SIAM IT LABS - Image Code Pack

এই ZIP ফাইলে আপনার বর্তমান ওয়েবসাইটে ছবি যোগ করার জন্য কোড রাখা হয়েছে।

ফাইলগুলো:
1. style-image-additions.css
   - এই CSS কোডটি আপনার বিদ্যমান style.css ফাইলের একদম শেষে যোগ করুন।

2. index-hero-image-snippet.html
   - index.html-এর Hero section-এ CTA button-এর পরে যোগ করুন।

3. services-images-snippet.html
   - services.html-এর Services section-এর উপযুক্ত স্থানে যোগ করুন।

4. work-portfolio-images-snippet.html
   - work.html-এর Portfolio/Our Work section-এর উপযুক্ত স্থানে যোগ করুন।

গুরুত্বপূর্ণ:
- এগুলো সম্পূর্ণ ওয়েবসাইটের বিকল্প ফাইল নয়; আপনার বিদ্যমান HTML/CSS-এর মধ্যে যোগ করার snippet।
- style.css আগে থেকেই HTML পেজে link করা থাকতে হবে।
- ছবিগুলো Unsplash-এর বাহ্যিক URL থেকে আসে, তাই ইন্টারনেট সংযোগ প্রয়োজন।
- পরিবর্তনের আগে আপনার বর্তমান ফাইলগুলোর backup রাখুন।
- Save করার পর GitHub-এ commit/push করুন এবং GitHub Pages deployment শেষ হলে Ctrl+F5 দিয়ে refresh করুন।
